Coder avec l'IA @Sirehna

Cette conférence de 1h a pour objectif d’exposer les différentes façons de coder
avec l’IA pour devenir un “Développeur Augmenté”.
Au programme :
- Les différentes vagues pour coder avec de l’IA
- Les outils majeurs avec un focus opensource
- Les méthodologies autour du Spec-Driven Development
- Des retours et des métriques sur l’adoption effectuée par d’autres entreprises
- Une démo de génération de code en mode Plan / Agent
