Are you creating or playing with Docker images everyday? You’re pushing them on K8S? Let’s discover a DevOps tool to improve your Developer eXperience: "Cloud Code". With the uses of Skaffold and Container Structure Test, you can reload your Kubernetes cluster seamlessly and quickly and validate your Docker images.

With a quick demo, we will use Cloud Code to make every day a productive day.
