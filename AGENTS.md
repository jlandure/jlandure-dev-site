# Agent notes

## Start the app

```bash
live-server .
```

Serves the Docsify site at http://127.0.0.1:8080.

## Skills

Two project skills live in `.agents/skills/`:

- **add-conference-talk** — add or update a talk, conference, meetup or speaking entry in `conference/README.md`.
- **add-slide-deck** — add or update a PDF slide deck under `slides/` (deck.md, cover, generated HTML).
